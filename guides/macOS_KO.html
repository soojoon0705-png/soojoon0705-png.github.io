BlobHUD 0.8.4 · 빠른 사용 안내

DaVinci Resolve · Apple Silicon 맥 · macOS 12 이상 대상

1. 설치·업데이트

Resolve 종료 → Install.pkg 더블클릭 → 관리자 인증 → 설치 완료 → Resolve 재실행.
Open FX에서 BlobHUD를 찾아 새 테스트 클립에 적용하세요. 업데이트도 같은 순서입니다.

2. 디자인 만들기

  1. 01 · 빠른 시작 → 추천 설정 적용을 누릅니다.
  2. 02 · 감지 대상 → 감지 영역 확인을 켜고 밝기·색·면적·범위를 조절합니다.
  3. 확인이 끝나면 감지 영역 확인을 끄고 디자인을 조절합니다.
  4. 03에서 라벨·색을, 04에서 연결선 모양·패턴·밀도를 바꿉니다.

3. 깜빡임 줄이기

06 · 안정화·사전 분석 → 클립 범위 가져오기 → 구간 분석을 실행합니다.
저장된 분석 사용을 켜고, 분석이 끝나면 프로젝트도 저장하세요.

다시 분석해야 할 때: 감지·안정화 설정, 원본 영상, 속도·리타임, 상위 효과·색보정을 바꾼 뒤입니다. 디자인·라벨 위치·선 패턴은 재분석 없이 바꿀 수 있습니다. 연결 대상 유지를 켰다면 거리·연결 수 변경도 재분석해야 합니다.

4. 기억할 점

  • 종이 라벨의 #RRGGBB는 입력 영상에서 감지한 평균 RGB입니다. 표시 변환 뒤 스포이트 값과 다를 수 있습니다.
  • 분석 구간 밖이나 설정이 달라진 구간은 프레임별 감지를 사용합니다.
  • 한 번에 최대 2,000프레임·64,000개 영역 기록을 분석합니다.
  • 빠른 교차·가림에서 번호가 바뀔 수 있습니다. 물체를 이해하는 AI 추적은 아닙니다.
  • 무거우면 재생 해상도를 1/2 또는 1/4로 낮춰 작업하세요. 최종 출력은 원래 해상도로 확인합니다.
  • 범위 가이드는 출력에도 포함되므로 최종 출력 전에 끄세요.

5. 제거·복구

Resolve 종료 → Uninstall.pkg 실행 → Resolve 재실행.
다시 설치하려면 Install.pkg를 실행하세요. 백업은 /Library/Application Support/BlobHUD/Backups에 보관합니다. 이전 버전으로 바꾸려면 먼저 제거한 뒤 이전 설치 파일을 사용하세요.

설치 경로: /Library/OFX/Plugins/BlobHUD.ofx.bundle
안내서: /Library/Application Support/BlobHUD/Documentation
LOCAL 파일은 개발자 서명·공증이 없는 로컬 테스트용입니다. 공개 배포에는 서명·공증한 배포본을 사용하세요.
