BlobHUD 0.8.4 - Quick Start

DaVinci Resolve - Apple Silicon Mac - macOS 12 or later

1. Install or update

Quit Resolve, double-click the Install_EN package, authorize installation, then restart Resolve. Search for BlobHUD in Open FX and apply it to a new test clip.

English and Korean packages replace the same installed plug-in. Parameter identifiers, choice indexes and saved analysis formats are shared. Back up important projects and check them after switching languages.

2. Create a design

  1. Click 01 - Quick Start > Apply Recommended Settings.
  2. Enable 02 - Detection > Detection Mask and adjust brightness, color, area limits and detection range.
  3. Turn Detection Mask off to see the design.
  4. Use 03 - Shape and Color for labels and colors, and 04 - Connections and Region Effects for connection shapes, patterns and density.

3. Reduce flicker

Open 06 - Stabilization and Analysis, click Get Clip Range, check the start and end frames, then click Analyze Range. Keep Use Saved Analysis enabled and save your project after analysis.

Analyze again after changing: detection or stabilization settings, source footage, speed or retiming, or upstream effects and grading. Design, label placement and line patterns can change without reanalysis. With Keep Connection Targets enabled, changes to connection distance or count also require reanalysis.

4. Things to know

  • Paper Labels show #RRGGBB from the detected average input RGB, with temporal smoothing when enabled. This may differ from a display-transformed eyedropper value. There is no automatic Log or Rec.709 conversion.
  • Frames outside valid saved analysis use per-frame detection.
  • Each analysis is limited to 2,000 frames, 64,000 region records and 16 MiB of serialized text. New analysis replaces the previous range.
  • Crossings, occlusions and fast motion may change region IDs. This is geometric region matching, not AI object tracking.
  • If playback is heavy, try half- or quarter-resolution playback. Check the final export at full resolution.
  • Show Range Guides is included in the output. Turn it off before final export.

5. Uninstall or restore

Quit Resolve, run the Uninstall_EN package, then restart Resolve. It removes the installed copy in either language. To restore BlobHUD, run an Install package. Backups are kept at /Library/Application Support/BlobHUD/Backups. To downgrade, uninstall the current version before running an older installer.

Plug-in: /Library/OFX/Plugins/BlobHUD.ofx.bundle
Documentation: /Library/Application Support/BlobHUD/Documentation
LOCAL packages have no Developer ID signing or Apple notarization. They are for local testing; use signed and notarized packages for public distribution.
