BlobHUD 0.8.5 - Windows English Test Build

Native Windows Resolve validation is pending.
Targets Intel/AMD x64 Windows 10 or later. Also check your Resolve version's requirements. Not for Windows ARM or 32-bit systems. The installer is unsigned and Windows may display a security warning.

1. Run the checks first

Extract the entire ZIP and run Run_Checks.cmd. No developer tools or administrator privileges are needed. It tests the actual plug-in ABI, rendering, saved analysis and installer engine in a temporary folder. It does not install or remove the system plug-in. Read Check_Result.txt afterward. If a check fails, stop and report the log before installing.

2. Install or update

Save your project and quit Resolve completely. Run BlobHUD_0.8.5_Setup_EN_x64_TEST.exe and authorize installation. Restart Resolve and search for BlobHUD in Open FX. The build uses static C++ runtime linking, without a separate C++ redistributable, Python or external font requirement.

English and Korean replace the same plug-in; only one language is installed at a time. Same-version switching does not require removal first. Keep a project backup and verify settings and saved analysis after switching.

3. Create a design

  1. Use 01 - Quick Start > Apply Recommended Settings for a new clip. Check saved settings first in existing projects.
  2. Enable 02 - Detection > Detection Mask and adjust brightness, color, area and detection range.
  3. Turn the mask off. Use 03 - Shape and Color for designs and labels.
  4. Use 04 - Connections and Region Effects for straight/curved connections, solid/dashed/dotted patterns and density.

4. Reduce flicker

Open 06 - Stabilization and Analysis, click Get Clip Range, check the range and click Analyze Range. Keep Use Saved Analysis on and save the project.

  • Limits: 2,000 frames, 64,000 region records and 16 MiB serialized text per analysis. New analysis replaces the old range.
  • Reanalyze after detection/stabilization changes, source replacement, speed/retiming or upstream effects/grading changes. With Keep Connection Targets on, distance/count changes also need reanalysis.
  • Designs, label placement and line patterns can change without reanalysis. Missing or invalid data falls back to per-frame detection.
  • Fast motion, crossings and occlusion can change IDs. This is geometric matching, not AI object tracking.

5. Color, playback and output

Paper Labels show #RRGGBB from average input RGB, with temporal color smoothing when enabled. No automatic color-space conversion is applied; values may differ from a display-transformed eyedropper. Try half/quarter-resolution playback for heavy scenes and inspect final exports at full resolution. Range Guides are included in output; turn them off before final export.

6. Uninstall or restore

Quit Resolve. Open Windows Settings > Apps > Installed apps and uninstall BlobHUD, or run the installed Program Files\BlobHUD\Uninstall.exe. The current bundle moves to Common Files\OFX\Plugins\@BlobHUD-Backups. Projects, media and documentation are preserved. The OFX standard excludes folders beginning with @ from plug-in scanning. Run Setup again to restore. Uninstall first before downgrading.

Plug-in: OFX\Plugins\BlobHUD.ofx.bundle\Contents\Win64\BlobHUD.ofx inside the system's 64-bit Common Files folder.
Guide: Program Files\BlobHUD\Quick_Start.html.
Actual Program Files/Common Files locations are resolved by Windows.
