BlobHUD 0.8.5 · Windows 한국어 테스트 버전

Windows Resolve 실기 검증 전 테스트 빌드입니다.
Intel·AMD x64 Windows 10 이상 대상이며 Resolve 자체의 요구 사양도 확인하세요. Windows ARM·32비트용이 아닙니다. 코드 서명이 없어 Windows 보안 경고가 나올 수 있습니다.

1. 먼저 파일 검사

ZIP 전체를 압축 해제하고 Run_Checks.cmd를 실행하세요. 개발 도구나 관리자 권한은 필요 없습니다. 임시 폴더에서 플러그인의 초기화·렌더·저장 분석·설치 엔진을 검사하며 실제 플러그인을 설치하거나 제거하지 않습니다. 끝나면 Check_Result.txt를 확인하세요. 오류가 나면 설치하지 말고 로그를 보내 주세요.

2. 설치·업데이트

프로젝트를 저장하고 Resolve를 완전히 종료한 뒤 BlobHUD_0.8.5_Setup_KO_x64_TEST.exe를 실행하고 관리자 인증을 완료하세요. 설치 후 Resolve를 다시 실행하고 Open FX에서 BlobHUD를 검색하세요. 개발 도구·Python·외부 글꼴·별도 C++ 런타임 설치 없이 쓰도록 빌드했습니다.

한국어·영어는 같은 플러그인을 교체 설치합니다. 같은 버전의 언어 전환은 먼저 제거할 필요가 없습니다. 기존 프로젝트는 사본을 저장하고 설정과 저장 분석을 확인하세요.

3. 디자인 만들기

  1. 01 · 빠른 시작 → 추천 설정 적용을 누릅니다. 기존 프로젝트에서는 저장 설정을 먼저 확인하세요.
  2. 02 · 감지 대상 → 감지 영역 확인을 켜고 밝기·색·면적·감지 범위를 맞춥니다.
  3. 감지 영역 확인을 끄고 03 · 모양과 색에서 디자인·라벨을 조절합니다.
  4. 04 · 연결선과 영역 효과에서 직선·곡선·점선·도트와 밀도를 조절합니다.

4. 깜빡임 줄이기

06 · 안정화·사전 분석 → 클립 범위 가져오기 → 구간 분석을 실행하고 저장된 분석 사용을 켭니다. 결과는 프로젝트에 저장하므로 프로젝트도 저장하세요.

  • 한 번에 최대 2,000프레임, 64,000개 영역 기록, 직렬화 텍스트 16MiB입니다. 새 분석은 이전 구간을 교체합니다.
  • 감지·안정화 설정, 원본, 속도·리타임, 상위 효과·색보정을 바꾸면 다시 분석하세요. 연결 대상 유지가 켜진 상태에서 거리·연결 수 변경도 재분석해야 합니다.
  • 디자인·라벨 배치·선 패턴은 재분석 없이 변경할 수 있습니다. 유효 분석이 없으면 프레임별 감지를 사용합니다.
  • 빠른 움직임·교차·가림에서 번호가 바뀔 수 있습니다. AI 물체 추적은 아닙니다.

5. 색상·재생·출력

종이 라벨의 #RRGGBB는 감지 영역의 평균 입력 RGB이며 저장 분석에서는 색상 평활화가 적용될 수 있습니다. 색 공간 자동 변환은 없고 표시 변환 뒤 스포이트 값과 다를 수 있습니다. 무거우면 재생 해상도를 1/2·1/4로 낮추고 최종 출력은 원래 해상도로 확인하세요. 범위 가이드는 출력에도 포함되므로 최종 출력 전에 끄세요.

6. 제거·복구

Resolve 종료 → Windows 설정 → 앱 → 설치된 앱에서 BlobHUD를 제거하세요. 또는 설치된 Program Files\BlobHUD\Uninstall.exe를 실행합니다. 플러그인은 Common Files\OFX\Plugins\@BlobHUD-Backups로 이동하고 프로젝트·영상·안내서는 남습니다. @로 시작하는 백업 폴더는 OFX 검색에서 제외하는 표준 구조입니다. 다시 설치하려면 Setup 파일을 실행하세요. 이전 빌드로 돌아갈 때는 먼저 현재 버전을 제거하세요.

플러그인: 64비트 공용 프로그램 폴더의 OFX\Plugins\BlobHUD.ofx.bundle\Contents\Win64\BlobHUD.ofx
안내서: Program Files\BlobHUD\Quick_Start.html
여기에 표시한 Program Files·Common Files의 실제 위치는 Windows 시스템에서 조회합니다.
