# BlobHUD

Free OpenFX plug-in downloads for DaVinci Resolve.

This repository contains the static product website, demonstration media,
installation guides and prebuilt installer ZIP files.
The plug-in C++ development source is not part of this repository.

## GitHub Pages

Publish the main branch, root folder in Settings → Pages.
No build tools or dependencies are required.

## Downloads

- macOS Apple Silicon: 0.8.4 LOCAL, Korean / English
- Windows x64: 0.8.5 TEST, Korean / English

These are unsigned test builds. Read the included guides before installation.
Package byte sizes and SHA256 are recorded in downloads/releases.json.
